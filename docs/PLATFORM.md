# 平台操作

## 系统设置

管理员在管理控制台配置注册开关、Worker 开关与执行超时。
暂停 Worker 会停止领取新任务；已开始的执行不会因此立即中断。
SMTP 支持 STARTTLS 或 SSL；修改连接信息时重新提供密码。
保存后使用测试邮件检查连接，接口接受不等于收件箱已投递。

支付设置支持 V1 共享密钥和 V2 RSA。新订单保存回调验签配置快照，
因此轮换配置不改变旧订单的验签规则。没有配置快照的旧订单仍使用
部署环境中的原支付凭据，迁移期间不要提前删除它们。

## 套餐与权限

新增套餐时可指定唯一 ID、标识、各周期价格、资源和运行配额。
分别勾选允许的插件以及创建资源、验证资源、编辑任务、手动执行、
定时执行和 API 访问权限。配额不等于权限，两者均满足才允许执行。
创建新套餐时不默认授予权限；编辑后请使用对应订阅测试。

有订单或订阅引用的套餐删除时会下架，保留财务关联；
无引用套餐可以物理删除。修改套餐不会改变已有订阅的权益快照。

## 用户与公告

用户账户管理支持创建普通用户、编辑资料、换绑邮箱及发送邮件。
邮箱换绑会撤销登录会话和 API 密钥，需要用户重新登录。
删除用户采用退役与匿名化处理，停用凭据、资源和任务，保留财务记录。
管理员账户不能通过此入口删除或停用。

创建并发布公告后，用户可从通知抽屉查看并标记已读。
已读状态按用户保存。目前通知为平台公告，不包含独立站内私信。

## 资源与运行日志

添加抖音 Cookie 后，后台 Worker 异步检查登录态并收集会话接口返回的好友。
检查失败的资源保持未验证；更新 Cookie 会清空旧好友并重新排队检查。
好友列表仅代表已加载会话，不是完整通讯录，也不证明消息已送达。
只使用本人或明确授权的 Cookie，切勿发送至公共日志或问题单。

任务中心运行记录可展开查看排队、开始、进度和结束事件。
日志不会展示原始 Cookie、消息正文或浏览器异常堆栈。
`TargetClosedError` 表示浏览器或页面已关闭，可能涉及进程退出、
运行资源或浏览器环境，不能仅凭此错误判定 Cookie 失效。
先检查资源验证状态、Worker 心跳与服务器进程日志，避免盲目重试导致重复发送。
